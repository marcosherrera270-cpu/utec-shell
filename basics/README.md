# basics

- 0-current_working_directory: imprime la ruta absoluta del directorio de trabajo actual.
- 1-listit: muestra la lista de contenidos del directorio actual.
- 2-bring_me_home: cambia el directorio de trabajo al directorio home del usuario. Debe ejecutarse con source.
- 3-listfiles: muestra el contenido del directorio actual en formato largo.
